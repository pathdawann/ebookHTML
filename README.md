# 🧱 Guía Interactiva de HTML · Serie Pathdawann (1/3)

Aprende **HTML** desde cero escribiéndolo y viendo los resultados en tiempo real en el navegador, sin configuraciones complejas ni distracciones.

🔗 **Explora la guía en vivo:** [hey-aprende-html.vercel.app](https://hey-aprende-html.vercel.app/)

---

## 🎯 Propósito del proyecto
Este proyecto nació con una idea simple: **aprender desarrollo web es un proceso continuo que se construye practicando paso a paso**. En lugar de leer teoría estática, aquí puedes experimentar con etiquetas, probar atributos, evaluar contraste de accesibilidad, armar la estructura de tu primer portafolio y poner a prueba lo aprendido.

## 🧭 ¿Qué encontrarás en esta guía?
1. **Fundamentos:** Qué es HTML, su evolución hasta el *Living Standard* y cómo el navegador construye el DOM.
2. **Anatomía y estructura:** Etiquetas, atributos, elementos vacíos y la plantilla base de todo documento.
3. **Explorador interactivo:** Vista previa en vivo de las etiquetas esenciales (`h1–h6`, `p`, `a`, `img`, listas, tablas, formularios, `details` y más).
4. **Semántica y accesibilidad:** Uso correcto de `header`, `nav`, `main`, `article`, `aside`, `footer` y calculadora de contraste WCAG en tiempo real.
5. **Práctica y autoevaluación:** Checklist de buenas prácticas con progreso guardado, quiz interactivo y constructor modular de portafolio.

## 🛠️ Stack utilizado
* **HTML5** semántico y accesible.
* **CSS3** puro (variables CSS, modo claro/oscuro automático y manual).
* **JavaScript (Vanilla)** sin dependencias externas, con persistencia de progreso mediante `localStorage`.
