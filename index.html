1¿Qué es HTML?

HyperText Markup Language: un lenguaje de marcado que describe la estructura y el significado del contenido. No es un lenguaje de programación: no tiene condiciones ni bucles. Es el esqueleto de la web.

El esqueleto. Define qué es un título, un párrafo, una lista o una imagen. Sin HTML no hay página.
La piel y la ropa. Controla colores, tipografías, espacios y el diseño en pantalla.
Los músculos. Añade comportamiento: menús que se abren, formularios que validan, juegos.

2Un poco de historia

  • 1989–1991 · Tim Berners-Lee, en el CERN, propone un sistema de documentos enlazados. Nace la web.
  • 1995 · HTML 2.0: primer estándar formal.
  • 1997–1999 · HTML 3.2 y 4.01: tablas, formularios y soporte para CSS.
  • 2014 · HTML5 es recomendación oficial: etiquetas semánticas, audio y video nativos.
  • Desde 2019 · HTML Living Standard, mantenido por WHATWG: ya no hay versiones, evoluciona de forma continua.

3Cómo funciona una página

Pulsa el botón para recorrer lo que pasa cuando escribes una dirección.

1El navegador pide la página a un servidor (HTTP).
2El servidor responde con un archivo HTML.
3El navegador lo lee y construye el DOM, un árbol de elementos.
4Descarga CSS, imágenes y JavaScript que el HTML menciona.
5Dibuja la página en pantalla.

5Estructura del documento

<!-- Todo documento parte de aquí -->
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
  </body>
</html>

doctype activa el HTML moderno · lang declara el idioma · charset evita que se rompan las tildes · viewport hace la página responsive · title es el texto de la pestaña y de los buscadores · body es todo lo visible.

9Accesibilidad

      
Una web accesible la puede usar cualquier persona: con lector de pantalla, solo con teclado o con baja visión. Casi todo se logra con HTML bien escrito.
